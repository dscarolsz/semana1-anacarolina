# Exercícios de Lógica de Programação com JavaScript

Repositório dedicado à prática e ao desenvolvimento do raciocínio lógico por meio de exercícios utilizando JavaScript.

Os exercícios abordam conceitos fundamentais da programação, como variáveis, operadores, estruturas condicionais, estruturas de repetição, funções e lógica de resolução de problemas.

**Objetivo:** fortalecer os conhecimentos em lógica de programação e aprimorar minhas habilidades na linguagem JavaScript por meio de atividades práticas e desafios.

Este repositório faz parte da minha jornada de aprendizado e desenvolvimento na área de tecnologia.
